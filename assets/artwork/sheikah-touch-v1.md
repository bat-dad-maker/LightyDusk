# Controles touch Sheikah — v1

Atlas: `sheikah-touch-atlas-v1.png` (1254 × 1254, RGBA, real transparency). Generated with the integrated tool `image_gen`, using the approved sketch as reference. The original PNG was copied without editing; the four regions are selected by UV in runtime.

The APK contains the atlas in `assets/res/sheikah-touch-atlas.png`. The skin only changes the presentation: layout, touch areas, gestures, editor, automatic visibility and control size maintain behavior. The menu button uses the Sheikh eye, designed in ImGui to remain clear.

Existing opacity multipliers remain: filling 40, pressing 120, border 110, text 200 and analog at rest 70 (all in scale 0–255), multiplied by configured opacity. The fading at rest of 0.6 remains. The alpha of PNG is multiplied by the same opacity of the edges; the leaked centers let the game appear.
